# Mundo Guaraci 3D

Protótipo interativo do projeto **Caminho do SUS — Guaraci**, com foco na linha de base de agosto de 2026 e no acompanhamento dos próximos 90 dias.

## O que já existe

- Página inicial com mensagem central do projeto
- Visualização 3D conceitual da unidade
- Setores clicáveis: APS/ESF, Gestão, Farmácia/Laboratório/Regulação, UCI/Especialistas e Urgência/Emergência
- Modo **Hoje** e **Daqui 90 dias**
- Animação conceitual do paciente pela rede
- Jornada do paciente
- Indicadores-base de agosto
- Foco de setembro: plantão, devoluções UCI → APS e separação de fluxos

## Arquivos

- `index.html`
- `styles.css`
- `script.js`
